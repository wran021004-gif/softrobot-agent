# 模型限制来源与解释

下表不把实现阈值当作物理结论。旧分析仍在 `matlab/closeout_mechanics.m`；新诊断版本为 `matlab/round4_mechanics.m`，保留同一方程与阈值。

| 分类 | 值和单位 | 来源 | 理由与触发含义 |
|---|---|---|---|
| 主任务成功条件 | 末端欧氏误差 ≤ 0.01 m，2 s 结束时 | `tasks/reach_free/task.yaml`、`configs/run.yaml` | 冻结任务判据；失败不等于工具不支持 |
| 用户授权包络 | L=0.05–0.80 m；布腱半径 0.002–0.018 m；3–8 根 | `capabilities/robot_families/tendon_driven_continuum/envelope.yaml` | 仿真探索范围，非制造或材料认证 |
| 本轮范围 | 布腱半径 0.018 m、8 根腱、体半径 0.020 m、8 离散段、1 连续体段 | `configs/experiments/round4_instruction.md`、`round4_authorization.yaml` | 本轮只有长度变化；越界拒绝执行 |
| 几何必要条件 | L ≥ ‖target−base‖−0.01 m | 三角不等式；固定长度连杆链、原点基座 | 小于此值无法满足到达容差；满足此值不保证可达或能控制到达 |
| 几何关系 | 0 < 布腱半径 < 身体半径，单位 m | 原包络关系约束 | 布腱点在截面内；不是受力安全认证 |
| PCC 结构分支 | 总弯角 0–π rad；单段、不可伸长、恒曲率 | `matlab/plan_pcc_reach.m`、PCC 物理契约 | 几何规划所选分支；不能据此给出动态稳定范围 |
| 简化力学结构 | 一个平面总弯角 q，n 个关节都取 q/n；运动在 XZ；忽略接触、面外弯曲、剪切、伸长、扭转 | `physics_contracts/closeout_analysis_v1.md` | 降阶假设；主模型有接触时不能输出同条件预测精度 |
| 静态搜索保护 | q∈[−2.8,2.8] rad；内部平衡要求 | `closeout_mechanics.m` 的 fminbnd 及残差检查 | **实现选择，尚未证明是物理有效范围**；触边表示没建立内部平衡 |
| 动态输出保护 | max |q| ≤ 2.8 rad | 旧/新简化分析的输出检查 | **实现选择，尚未证明是物理有效范围**；已接受输出越界也不返回完整成功预测 |
| 动态内部试算保护 | |q_trial| ≤ 3.2 rad | 简化分析 rhs | **实现选择，尚未证明是物理有效范围**；试算点可能不是已接受状态；触发为程序保护中止 |
| 输入保护 | 每根张力 0–20 N；初态角 ±2.8 rad、速度 ±10 rad/s | `schemas/analysis_spec.py` | 继承分析接口范围与执行器约束，不是独立验证过的材料范围；面外力属于条件不适用 |
| 静态数值保护 | 残差 ≤1e−6 N m；TolX=1e−10 rad；最多120次迭代/160次函数调用 | MATLAB 简化求解器 | 实现数值选择；求解收敛不意味着物理模型正确 |
| 动态数值/时间预算 | 时域≤4 s；采样≥0.001 s；RelTol=1e−7、AbsTol=1e−9、MaxStep=0.01 s；旧/新求解保护30 s | MATLAB 与 AnalysisSpec | 数值精度/资源约束；不是任务条件。新 Engine future 另有45 s等待上限 |
| 本轮执行预算 | 长度24模型/28执行；开发12执行/24求解 | 本轮用户指令、`tools/round4_budget.py` | 调用前扣账；失败/中断消耗额度；不能为找成功追加轮次 |
| 稳定开发任务 | 世界系目标；segment_7 外力脉冲0.5–0.7 s，0.08–0.12 N；评价0.8–2 s最大误差≤0.01 m | `tools/task_family_tools.py` 开发版本 | 用小外力和留出恢复窗口验证接口；**实现选择，未经正式基准批准**；基座运动是另一物理任务，当前未实现 |

主任务历史三次失败只保存了异常消息，触发时刻、状态和最后有效样本无法恢复。逐条审计位于 `runs/round4/historical_failure_audit.json`。一次代表拉力输入复查使用原来的施力阶段时间戳，并在新版本中记录内部试算点及已接受输出；其部分轨迹只作诊断。

独立单铰链动态对照与主软体机器人任务分开：正角绕 −Y，末端向 +Z；J=Iyy+m·cx²，重力和接触关闭，两边施加恒定广义力矩。它检验后端时间、坐标和动态数据比较能力，不证明单总弯角近似适合主任务，也不提供真实材料标定。
