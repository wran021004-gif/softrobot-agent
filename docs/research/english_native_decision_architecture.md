# English-native research decision architecture

The integration base is `91573147e7a2bdf0044cf9621fbf4929568d9377` on `codex/agent-guided-codesign`. The opt-in `english_decision_v1` Study contract uses the existing Store, Strands session, evidence admission and evaluator. Historical Studies keep their frozen behavior. The original implementation milestone used no live Provider request, scientific worker, physical rollout, NMPC or training. The later bounded provider-only decision probe is documented below.

## Ownership and roles

`config.py` freezes the versioned role and handoff policies. `agent.py` owns actual Strands tool definitions, request construction and accounted transport. `research_context.py` projects Store facts into `research_decision_brief_v3`; `reporter.py` composes read-only reports and validates sources. `core.py`, `evidence_policy.py`, `evidence_views.py` and the registered evaluator retain evidence identity, formal reads, admission and task acceptance. `provider_context.py` estimates serialized input tokens and preserves the hard guard; `session_handoff.py` owns verified SDK snapshot rotation. `experience.py` retains optional procedural guidance and grants no scientific authority.

New Studies opt in inside `research_decisions`:

```json
"architecture": "english_decision_v1",
"role_policy": {
  "version": "research_roles_v2",
  "main": {"thinking": "disabled", "reasoning_effort": "none"},
  "reporter": {"thinking": "enabled", "reasoning_effort": "low"}
},
"handoff_policy": {"version": "token_handoff_v1", "input_tokens": 38000}
```

The handoff policy defaults to the shown threshold for the opt-in architecture; the resolver verifies it fits beside output and framing reserves. Both roles share the frozen model, endpoint and accounted Store ledger. In `research_roles_v2` both wires omit `max_tokens`; null is also accepted in the role profile. This uses the Provider default, not infinite capacity. A 32,768-token context-planning reserve plus the frozen framing headroom is retained even though the request does not set a generation cap. The reserve is a conservative local planning margin, not a claim about guaranteed Provider output or context capacity. Existing `research_roles_v1` role caps and exact saved-wire replay remain unchanged. DeepSeek documents the profile values at [the Chat Completions reference](https://api-docs.deepseek.com/api/create-chat-completion/).

## Evidence, decisions and recovery

New instructions, tool guidance and Reporter prompts request English at source as an authoring convention. Explicit reads return the original historical evidence and provenance, including Chinese text. No translation, language classification, Unicode-based rejection or evidence rewriting occurs. Historical artifacts remain unchanged. Formal read credit and source validation are independent of language.

The L0 brief shows task and candidate state, sourced metrics and model quantities, the latest source-grounded Reporter conclusions (v1 uses bounded excerpts), current action directions and budget, and evidence/closeout navigation. An action menu entry is a request-level eligibility indication; actual parameter, source, model, identity, Study authorization and resource checks remain authoritative at dispatch. SELECT needs the Main Agent to receive a complete fresh passing independent evaluation through `evidence_read`; Reporter reads and partial/withheld reads do not count. Multi-condition SELECT retains the original all-conditions and same-structure checks. STOP retains the exact registered result citations and existing gate.

In the ordinary decision request, `research_analysis` and its full method union are absent. Direct legal `research_plan` actions remain available. A settled diagnose decision naming an owned candidate and registered authorized method exposes that method's pruned `AnalysisRequest` schema on the next request; the original dispatcher remains the execution authority. The selected candidate and frozen protocol are bound in that schema. This path costs one additional Main tool round before a mathematical execution; simple Plan actions need no such round. Existing exact-wire replay restores the originally saved tool definitions.

Reporter priority retains deterministic feedback for ordinary/repeated cases and selects Low for new incomplete or changed complete results, a detected model/physical constraint mismatch, or explicit investigation. The v2 prompt asks for concise conclusions without a fixed word-count requirement; frozen v1 retains its existing prompt. It cannot change facts, admit actions, or grant read credit. Full reports stay retrievable.

When existing live handoff admission is enabled, the projected complete SDK request, including current L0 and tool definitions, is tokenized using the pinned offline tokenizer. Threshold rotation uses the existing verified completed-invocation or paired-feedback boundary. The new session is rebuilt from the Store and carries pending feedback when required; no old reasoning transcript is replayed. Unknown sends, unmatched feedback, unsettled receipts and active workers still block rotation. Output reserve and framing headroom remain separate from the soft input threshold. No provider token count or billing is inferred from this estimate.

## Evidence delegation and v2 probe boundary

For `research_roles_v2`, `main_evidence_navigation_v1` bounds ordinary Main tool results to an approximately 4 KiB navigational index. Root working sets always produce an index; oversized summaries and nested results point to actual source fields or bounded ranges. Small exact field reads retain original values. Detailed interpretation is delegated through the existing settled `research_investigate` path. Reporter gets selected detailed reads internally, while Main receives source-grounded final interpretations and deterministic facts, not Reporter reasoning or selected-read payloads. The Main can still inspect the original evidence explicitly. The exact root `view=full` formal SELECT read is not projected; existing wire-delivery coverage and closeout admission reject an offloaded or incomplete result. STOP retains its exact result index and original admission.

The original C3 child execution sessions and sealed manifests were located read-only and copied into an isolated fixture with their original owners and execution IDs. Historical call rows are preserved as archival artifacts, not charged to the probe ledger. A subsequent authorized live probe used seven Main requests and one Reporter-Low request, with no scientific workers. Diagnosis settled and the selected braking schema appeared, but the model submitted invalid candidate and protocol types twice; the last attempt was also blocked by protected closeout. A targeted field-specific error and smaller navigation index were added afterward and verified offline. The unchanged scientific guard rejects historical execution because dependency hashes differ; readiness for an autonomous Study remains unproven. See the [v2 probe report](main_off_decision_probe_v2.md).
