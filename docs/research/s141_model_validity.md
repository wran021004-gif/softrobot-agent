这些是仿射状态上的非线性检查，不是非线性积分轨迹，更不是 GVS/MuJoCo 一致性证据。

对 B1 的五个问题，最终回答如下：

1. **是，就原直臂仿射饱和而言。**轴向一阶退化造成共同虚假下界；数值求解本身已收敛。
2. **局部几何效应可以区分，可信结构排序仍未知。**弯曲点改善明显，但有效静态工作点未得到，动力学/优化收益未验证。
3. **只能局部指导。**完整轨迹的几何和动力学一致性仍不合格，不能外推局部精度。
4. **没有超过数值和代理误差的改善证据。**相同合法控制重优化后仍平分；非线性代理差远大于分数差。
5. **暂停 B1。**不保留为下一次 Agent Study 任务；不增加目标、结构扰动或 Benchmark。

最强科学结论是：**现有 GVS 在一个实际返回且独立核验的非平衡弯曲状态附近，
能更准确表达几何位移及固定状态下的长度分配效应；它尚不能提供当前完整任务的可信结构方向或候选排名。**
没有得到物理收益、全局可达性、稳定性或硬件结论。此负结果足以决定暂停，故不消耗可选 MuJoCo 对照。
