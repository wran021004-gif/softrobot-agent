## Increment and outstanding work

The current increment adds a four-category action index for agent-choice family Studies, a non-destructive scientific-status projection and avoids presenting unscored search records as incumbents. It adds an explicitly granted `normalized_joint_block_v1` method: deterministic simultaneous continuous moves are normalized, share a single bound-limited scale, and are compiled and scored through existing paths. Frozen legacy coordinate grants remain unchanged. The method currently rejects aggregate or fixed-total length constraints; it is not an adaptive trust-region optimizer. Its test uses synthetic scores and is not physical evidence.

Existing V2 routes may start on an intermediate guide and must not be represented as V3 compliant. No new physical task acceptance or P2/P3 study was performed. These are blockers to the requested end-to-end P2 readiness claim.
