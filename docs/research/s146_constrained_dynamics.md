# S146：同维 MuJoCo 虚功约束动力学预测对照

**结论：保持现有 12 维曲率状态，同维离散 MuJoCo 虚功约束动力学在两个固定区间均明显改善预测。**
主区间 0.34–0.35 s 的曲率率误差由 **42.48905 降至 14.78965 rad/(m·s)**；
相同 GVS 运动学下，相对真实终点投影的末端速度误差由 **0.01840384 降至 0.01447139 m/s**。
独立邻区间也改善，两套相同读出下均成立。改进来自动力学替换，不能全部解释为读出几何变化。

这支持把连续/离散动力学差异列为重要原因，但没有证明某个力学项是唯一主因。
剩余误差仍大，未表示自由度、快模态、动力学闭合和时间离散仍是竞争解释。
本轮没有修改生产模型、Basis、NMPC 或物理参数，也不据此宣称 Reach/Hold 任务性能提升。

## 2. 同维虚功约束动力学

复用原 `discretization_jacobian` 得到固定的 **T∈R^(48×12)**，秩 12、条件数 **2.8445728**。
复用 `project/discretize` 核对物理状态与 12 维系数之间的转换。
在每个求值点 x=[q,qdot]，令物理关节状态为：

```text
qpos = T q
qvel = T qdot
Mr = Tᵀ M_MJ(Tq) T
Fr = Tᵀ (qfrc_actuator + qfrc_passive − qfrc_bias)
Mr qdd = Fr
```

使用具名关节索引重排原 MuJoCo M 和 force，再作虚功投影。
固定 T 不引入额外 Tdot 项。`bias` 已含原离散模型的惯性偏置与重力约定，未重复加重力或速度项。
本轮求根残差直接使用 `Mr·qdd−Fr`；初始化检查另用 `solve(Mr,Fr)`，
与 S145 保存的同态 constrained qdd 核对，未将完整 MuJoCo qacc 投影后冒充约束动力学。

单位：物理角度 rad、角速度 rad/s；q 为 rad/m、qdot 为 rad/(m·s)、qdd 为 rad/(m·s²)。
T 的长度因子单位为 m；广义质量为 kg·m⁴、广义力为 N·m²，rad 视为无量纲。

所有 `mj_forward` 都在私有 MjData 上进行，显式设置保存区间的终点 engine time，
原张力固定。该模型没有时变外力或执行器动力学。
每次检查实际张力与输入相同，gain=−1、gear=1、tendon 绑定顺序正确；
`ncon=0`、`nefc=0`、constraint force/applied forces=0，warning 计数=0。
检查完整物理质量平衡只是核验原力学求值，不将其加速度用作约束空间动力学。

## 3. 积分协议与比较定义

复用 `gvs_trajectory.implicit_step_residual`，保留：

- **1×0.01 s implicit Euler**，同一时间区间、同一实测投影起点和实际输入。
- **CasADi Newton**，`abstol=1e-10`、`max_iter=30`、`error_on_fail=True`，其余求根选项沿用默认。
- 相同初始猜测：起点状态；q/rate 缩放分别为 **10 / 1000**。
- 原运动学残差除以 **10**、原力平衡残差除以 **0.001**。

只有局部的 CasADi Callback 用 MuJoCo Mr/Fr 替换 GVS 力学求值。
该回调缺少解析 AD，采用预先固定的**归一化状态前向有限差分**构造所需 Jacobian；
不改积分方程、求根容差、步长或初始猜测，不使用新的求解框架。
先运行合成线性力学 fixture 核验回调残差和 Jacobian 接线，随后提交固定脚本，再启动真实数据计算。

比较对象为：

- **A**：已保存的原 GVS 预测。主区间用 S144 原 A 高精度 root 结果；邻区间用 S142 accepted-plan 预测。
- **B**：本轮新同维 MuJoCo 虚功约束动力学预测。
- **C**：原真实 MuJoCo 终点分别 project 后的 24 维状态。

主要输出误差为 A−C、B−C。每套读出分别在 A/B/C 上使用同一个运动学模型：

```text
GVS 读出：    v_g(x) = J_GVS(q) qdot，含原世界坐标变换
离散读出：   v_d(x) = J_MJ(Tq) T qdot，原 MuJoCo site Jacobian
```

不能把 A 的 GVS 读出与 B 的离散读出相减宣称动力学收益。
另单列相对于原完整物理终点速度的误差，保留投影/几何误差的影响。

运行前固定局部“明显改善”规则：两个区间的 q、qdot 误差范数，以及两套相同读出相对 C 的速度误差范数，
**均至少降低 20%**。这是描述性的本例判别门槛，不是统计显著性或任务验收阈值。

## 6. 判别与下一步唯一推荐

**在相同状态维度、同一积分与每套相同读出下，替换动力学确实改善两个区间。**
因此当前误差不能仅解释为“12 模态没有表达足够关节速度”；
连续/离散动力学的差异本身足以显著改变本例预测，值得优先定位。
不过 B 主区间相对 C 的速度误差仍为 **0.01447–0.01635 m/s**，模型没有被完全修好。

本轮一次替换的是整体力学来源，不能将收益独立归给质量、重力、被动力或腱力中的任意一项。
未表示自由度/快模态的动力学闭合、同一个 0.01 s 隐式步的数值效应仍可能贡献剩余误差。
不推导必须增加模态，也不立即把此局部回调接入生产 NMPC。

**下一轮只推荐检查广义质量矩阵的连续/离散装配差异。**
保持现有 Basis、张力和其他力学项，围绕相同可表示构型，核对
`M_GVS(q)` 与 `TᵀM_MJ(Tq)T` 的分段/模态块、质心位置、平动/角速度 Jacobian 及质量积分。
S145 已在这两个起点观察到约 **7.84% / 7.83%** 的质量矩阵相对 Frobenius 差，
大于该次比较的主要重力、腱力、弹性和阻尼项相对差；速度偏置虽相对差更大，绝对量很小。
这些百分比来自不同物理量，不能据此直接证明质量是最大因果贡献；
选择质量项只是一个有具体证据的最小检查优先级，尤其考虑约 `9.4e4` 的条件数。
先判明它是预期几何离散差还是确定装配缺陷，再决定是否值得单项原型或生产修复。

本轮在两个区间完成后停止。没有执行这项后续检查、单项替换、参数扫描、模态搜索或其他目标优化。
