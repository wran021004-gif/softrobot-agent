### 给 Agent 的独立 L1 决策视图

当前接口已经足以表达本轮三层事实：归一化本体控制权、T1/T2 局部数值可靠性、
有限 native 控制重优化与原独立任务验收。所缺的是可信模型区域和控制最优性证据，
不是新的闭环数学接口。新增纯函数 `task_control_capability_comparison` 组合原
`recorded_score_resolution`、`compare_acceptance` 和既有证据，不新增 Store/ResultCard/阈值。

- **可用于预筛选的事实**：当前 X 一阶失驱动及共同 −0.2 下界；它能筛掉继续用这个
  初始工作点 T1 对刚度做自动排名的无价值计算，不能据此淘汰任一物理结构。
- **可帮助设计下一实验**：共同 U0 的结构响应确实不同，控制重优化可明显补偿；
  若另获授权，应优先验证模型在实际弯曲/制动状态的同输入输出误差，以及固定结构控制搜索收敛性。
- **仅局部诊断**：输出 Gramian 的横向谱、不可驱动轴、冻结频域曲线、T2 条件包络和单尺度割线。
  这些不提供 0–8 N 有限时域可行性、非线性/闭环梯度或硬件保证。
- **何时继续控制优化**：本轮两次更新仍明显改善且触及信赖域，控制搜索质量是未决项；
  先验证额外优化机会是否改变已找到顺序，不将继续计算自动视为本轮授权。
- **何时值得修改结构**：d+ 可成为有理由的经验物理对照，依据是本轮实际响应，
  不能称 T2 推荐或已证优胜；须与同算法、同起点规则和足够控制机会比较。
- **何时先诊断模型**：原 T1 在轴向下界饱和、同输入 GVS/MuJoCo 差明显时，
  应优先验证任务代理/工作点。不能直接判定 T2 数学公式错误，也不在本支线重构 GVS。
- **最小开放内容**：任务/结构/模型身份、工作点/时域/输入盒、输出尺度与失驱动轴、
  T1 原值/支撑区间/活跃约束、T2 原 direction_status、控制处理、三个原物理指标、
  求解停止状态/成本及精确原始指针。保留 unresolved 与不支持结论，不注入每轮 L0。

这能减少“用已饱和局部代理反复算刚度排名”的无价值数学/物理尝试，
尚不能证明能减少多少实际实验，亦不能把它升级为 Agent 自动结构排名器。
后续优先级为 **GVS 任务代理可信度与控制搜索质量的辨别**，其次再决定敏感性参数/工作点；
科研交接的最小派生接口已足够，本轮没有证据要求扩大参数目录或修改 R1。
