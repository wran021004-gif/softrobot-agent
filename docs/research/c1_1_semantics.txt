Semantics
For each numerical constraint, the existing signed violation is divided only by its explicit positive legal scale from the nonzero frozen bound. J is the maximum signed normalized violation. normalized_gap remains max(0,J). A zero bound never obtains an epsilon, default scale or weight, even if a stale normalized value is present.

All frozen constraints remain recorded. Constraints without a legal continuous scale are hard gates. J exists only when every frozen condition has complete valid data, the numerical observations are finite, at least one numerical constraint exists, and every hard gate passes. A failed gate retains its observed value, bound and failure; observation_feasible is false, J is null, and the point is ineligible as a scalar improvement. Only gates, with no numerical objective, give feasibility_comparison_only. Independent evaluator/certificate authority is unchanged.

Derivative status and candidate improvement are separate. The existing two-scale finite differences still check consistency and signal resolution. A maximum-constraint switch is nonsmooth; a hard-gate transition is discontinuous; an invalid stencil has no reliable derivative. All dynamic strict_derivative flags remain false.

A complete legal point can nevertheless have candidate_improvement_status=observed_full_task_improvement when its directly measured J improves over the same eligible baseline by more than the existing resolution floor max(1e-12,abs(J0)*1e-9). This floor checks observed improvement; it does not normalize a hard gate. Physical model change, original authorized parameter domains, the frozen task, seed, backend, dynamics model, controller and discretization must agree with the comparison contract. Optimize candidates also remain inside the existing local bounds. Generation metadata is allowed to reflect the changed structure. The existing bounded Powell and perturbation stencils are retained. No gradient consistency across all parameters is required to recognize a measured dynamic candidate; the active/static selection checks are retained.

The direction remains a proposal through the original research_plan/generate handoff. full_task_improvement_verified remains false: the directly measured task objective improvement grants no independent acceptance, strict descent, global optimum, or SELECT eligibility.
