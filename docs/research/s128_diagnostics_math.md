静态 IFT 具体为 `R(q,u)=0`、`dq/du=−R_q⁻¹R_u`、`dp/du=p_q dq/du`。实现要求静态残差合格、`rcond(R_q)>sqrt(eps)`，并在**一个确定的混合输入方向**上比较正负扰动的重新求平衡结果。这是数值方向校验，不是每列 Jacobian 或整个邻域的物理验证。固定输入工作点当前取候选预张力；本轮四个零预张力候选若走此路径，`u±h du` 的双边物理界检查会失败。不能假定它们都能直接产出 `mathematical_response` 种子，也不能把失败解释为无输入作用。无需为了第一轮筛选改内核：用显式初始点/实际 saved_state 的动态线性化及其单边输入盒；已有 0.2 N 候选才是可尝试静态 IFT 的内点对照，仍须通过求平衡与条件检查。

`trajectory_feasibility` 从 `controller_start_input` 或 `standardized_initial_pretension` 的真实初始化时间零开始，才可能覆盖原任务全部 13 个约束/样本对（终点 1，保持位置 6，保持速度 6）。`full_task_supported=true` 仅表示表达与时间覆盖完整，**不是可行**。从 0.30 s saved_state 起只剩五个未来控制区间，过去样本不补证；默认 `halfway_waypoint` 无真实任务起点，不适用于此轨迹操作。未知信号、物理/非凸约束、非对齐网格等明确保留缺口。

## 5. 跨候选的控制潜力：哪些可比

必须先固定“比较的科学量”：同样任务下已测控制的表现、局部模型的输入作用、受限控制类的最优表现，是三个不同问题。

| 量 | 何时可比 | 本轮能否用于结构排名 |
|---|---|---|
| 原物理三指标及 `max(0,value/limit−1)` 的最大 gap | 同目标/阈值/采样/有效完整执行与评价协议；保留候选与控制来源 | 能排已测组合，不能排最佳可达能力。不同候选评估次数 0–60，选择偏差很大。 |
| 有界 trajectory/endpoint 的见证、排除证书 | 同模型实现、协议、真实输入界、工作点构造/时间原点、覆盖与检验容差 | 可比较结论范围；S12.8 没有这些 analysis 结果，不能补造排行榜。一个 witness 与另一个 inconclusive 不构成能力优劣。 |
| 位置输出 Gramian 的最小特征值、最小能量/目标投影 | 同 input/output 归一化、保持或连续输入定义、窗口、模型实现和可解释的工作点构造；候选各用自己的模型 | 可作任务相关局部假设。无张力单边界，不能作为硬否决。输入通道增加在“各腱同尺度”时也改变总能量预算，需声明是每通道还是共同总资源比较。 |
| 全状态 Gramian 的秩、特征值、条件数 | 相同状态语义、坐标/尺度和维数；明确阈值 | 三段与两段直接比较特征值/秩无效。相同维数也不自动同物理工作点；rank 缺失不证明非线性不可控。 |
| `dp/du`、目标方向投影、张力余量 | 同物理单位、相同类型静态分支、匹配输入/构型、通道作用和单边可用幅度 | 不能把静态 m/N 与 0.35 s 物理响应 m/N 混排。不能只取 Jacobian 大小忽略目标方向、速度和上/下界。 |
| 极点、频率奇异值、阻尼指标 | 平衡点和同模型定义；非平衡只解释冻结 Jacobian | 不能把高黏性下的某个权威指标解释为动态保持成功。authority_threshold 未定义，不能编造“有效带宽”。 |
| NLP objective、搜索 predicted improvement | 完全同目标定义/缩放/松弛/网格/候选/起点与基函数 | 本轮多个结构/权重/时域问题混杂；objective 115.64 不等于物理误差，更不等于最优能力。 |

冻结 protocol 已固定 input_scale=8 N、output_scale=0.01 m、窗口 `[0.05,0.1,0.35] s`，曲率尺度采用冻结 family 默认长度而非每个候选新长度，这是已有比较语义的一部分。不能在排名时私自改尺度或把 0.05 s 与 0.35 s 分数并列。同一候选从实际 t=0.30 s 开始的余时域也不能与名义 0.35 s 相比。减小/增加控制结点应明确控制函数类：第一轮 S12.8 response 搜索是前三腱、四结点的 12 个系数，第二轮为两系数，不等于 35×6 全自由输入搜索；数学允许的每区间 ZOH 控制类与它们不同。

## 6. 为什么 S12.8 没有调用 research_analysis

### 6.1 已确认事实

实际请求与动作审计见派生文件 `/request_advertisements`、`/packet_metadata`、`/advertisement_summary`：

1. 59 次实际 Provider 请求全部包含 `research_analysis`；只有一个分析工具 Schema/描述版本，身份 `f9fc6e48…`。`candidate/operation/protocol` 为必填，九种操作、六种工作点全部广告；`analysis_protocol` 在全部决策包中可见。工具描述中确有 `Historical candidate binding required`，但源码接受当前生成候选，不以“必须有历史候选”为条件。
2. 全部 packet 的 readiness 为 `ready`、`remaining_mathematical=8`；capabilities 含 `analysis`。`agent.before_model` 确有 readiness/数学余量/closeout 移除工具的分支，但本次线上的 59 份广告证明没有被移除。已广告不等于已做某候选数值预检，也不保证一次请求就数值成功。
3. 模型原生调用只有 `research_plan=34`、`evidence_read=34`，`research_analysis=0`；Store `analysis_results=[]`、数学计数 0，没有分析工具拒绝、失败或排队请求。因而不存在“尝试数学后被 Schema/额度拒绝”的已存事件。
4. 动态 Plan action enum 是 `generate/initialize_control/physical_replay/control_search/execute/mechanics/...` 所属的另一入口；`research_analysis` 是独立工具，不应要求它进入 Plan enum。可是 `available_research_actions` 中确实没有一个直接分析条目；候选出现后，已有的 `initialize_control/mathematical_response` 累计出现 148 个候选级条目，全部 `blocked`，因为缺少 verified input sensitivity。148 是跨轮展示次数，不是 148 次尝试。这是展示事实，不是分析不能调用。
5. 实际动作走了生成/修改结构、固定控制、两次 `physical_response`、两次 response search、一次 NLP 和两次 NMPC。NLP artifact `90bc0b90…` 在 a0a831fd 候选上运行 78 次迭代、176 次函数评估，`converged=true`、`relaxed_feasible=true`，但 `original_feasible=false`、结论 `inconclusive/requires_independent_replay`。原 warm-source 拒绝后改 cold solve，不是 `research_analysis` 的拒绝。

### 6.2 合理假设，尚无因果验证

候选级动作清单突出可立即执行的物理/优化路线，却只把数学响应呈现为缺前置证据的 blocked 项，可能提高了发现独立分析入口的成本。描述中的“Historical”也可能使 Cold-start 下的新候选分析显得不明确。默认工作点是 halfway，而静态灵敏度和完整轨迹分别需要另外显式选择工作点，调用负担真实存在。这些是从接口与动作的关联提出的**可证伪假设**，不是已证明的 Agent 心理原因。

也可能 Agent 根据其假设偏好直接物理探测/优化，或低估数学信息价值。已存 hypothesis/selected_method 文字只是模型自述；S12 原验收已经展示过“文字说静态平衡、实际执行动态 NLP”的错位。科学判断应以 typed payload/receipt 为准。不能把未调用简单归因于工具隐藏、readiness 失败、额度不足、上下文截断或“模型不会数学”；本轮无确认截断，且广告直接反驳隐藏说。

### 6.3 现有记录无法确认

不能从 59 次未调用推断换一种广告/提示就会调用，更不能推断会节约多少物理预算或一定成功。不能确认 Agent 是否理解所有枚举和前置条件、是否有意识排除了静态 IFT、或是否预见模型不适用；它没有提交相应分析动作。也不能把到 STOP 只剩一次物理启动后 PPO 不再满足两启动准入，解释为 PPO 或数学无效。证明接口因果作用需要后述隔离决策对照，不能用新的研究结果倒灌原 Cold-start。

## 8. 可证伪的归因链与更便宜的方向发现

链条应是：**声明范围的数学预测 → 相同候选上的显式控制 → 独立原任务物理评价 → 核对预测与实测差异 → 修订具体假设**。预测要在看新物理结果之前写明对象、方向、幅度、有效时间/样本、预期改善和反证条件；把“有改进的预测”与“达到原阈值的预测”分开。数学见证的对照必须执行其实际输入或明确的控制参数化映射，不能换成另一条轨迹后声称验证了见证。

| 观察组合 | 更受支持的归因/下一步 | 反证与限制 |
|---|---|---|
| 数学给出有界采样见证，物理也通过；原控制失败 | 原控制选择/优化/控制类受限的解释增强；优先保留结构 | 单个实例不说明普遍可控或鲁棒；还需原 evaluator 完整验收。 |
| 同候选、同模型与输入，数学见证物理失败，预测误差超出事前范围 | 先查输出维度/时序/输入一致性、投影、积分与模型假设 | 不能立即归因结构。数值内核自校验成功也不建立物理一致性。 |
| 同候选可表达的较丰富控制成功，而原较小基函数类失败 | 参数化限制解释增强 | 若只是不等预算/不同起点，仍可能是优化不足；较丰富类也失败不证明结构不足。 |
| 数值残差/KKT 不合格、迭代上限或回放不一致 | 优化/构造未解决，先定位优化点与校验 | 不能把 `inconclusive` 升级为 infeasible，也不能强制导出结构梯度。 |
| 某有界必要条件在局部模型中有正的排除余量 | 可提出具体输入方向/几何假设或审查工作点/模型 | 只排这个模型/输入盒。非线性路径可离开工作点；没有经验证的模型误差界不能作物理结构硬否决。 |
| 在校验过的同一局部工况，单一结构/路由变更带来预测且实测的作用改善 | 该工况下结构作用的解释增强 | 不能外推最优控制提升、全空间结构优劣或硬件结论。 |

方向发现可直接利用现有量，而非先为每个系数跑整条 MuJoCo 差分：静态内点的 `dp/du` 用现有 `mathematical_response → directed_inputs` 做有界正则拟合；动态用已有 A/B/Cv、ZOH 与 `sampled_maps` 把末端/速度残差映射到可用张力方向。若控制采用结点系数 θ，现有采样输入映射记为 `δU=Pδθ`，则任务样本方向就是 `M Pδθ`；这是读取/组合现有映射，不是新求解器。要同时看保持位置和速度行、实际上下界、允许幅度，不能只挑最大奇异值或最大的静态位移。

对零预张力，用 `0≤u0+δu≤8` 的可行方向和现有 bounded endpoint/trajectory；不能以无约束 Gramian 的正负对称方向替代。对实际运动中的制动，先用已存 NMPC execution/update 绑定相同状态与剩余时间；`instantaneous_braking_v1` 只提出点态假设。映射可提出少量方向，但当前 response-search 接口仍自行做物理差分；**不能声称已经能把任意数学 Jacobian 直接注入它**。已有数学响应交接仅是静态、常量输入初始化路径。任何未来映射适配应在原命名空间/契约内完成。

S12.8 两次物理响应初始化共 14 次启动；response 搜索共 52 次差分评估，57 次新启动（不把缓存基线当新实验），其中第一轮 48 次差分对应 12 系数×4 次迭代，另有 10 次因裁剪无效的方向尝试但没有重复相同实加输入。数学导向可能减少被测试方向数量，**不能预先宣称必然节省墙钟时间**：MATLAB 启动/导数有成本，模型方向也可能错误。应实测每个有效改进/被证伪假设花费的数学时间、物理启动数及 Provider 成本。

## 9. 最值得进行的三个受控实验（未执行）

下列不重开原 Study，不改其标准；未来如实施，使用单独的受控分析/验证记录，保持不可变来源。资源类别是规划，不是已获执行授权或实测耗时。

### 实验一：封存轨迹上的预测接口与局部模型校准

**所需数据与固定条件：** S12 成功四腱原配置/35×4 输入；S12.8 两次 NMPC 的 accepted plan、observations、完整 `mathematical_facts`、实加输入、物理运动、时间戳、投影残差及模型/积分身份。先只读验证末步完整输出和矩阵形状，区分标量退化与真实模型误差，不覆盖坏 artifact。按预先固定的早期/制动工况分组，评估向量误差和“增量误差”，不用损坏的最大值筛工况。现有四腱专用诊断需先验证 6/7 腱适配边界。

**可区分的假设与反证：** 若修正派生读取后大误差消失，则“巨大物理模型偏差”被削弱，支持输出接口解释；若维度正确、输入/时间对齐后仍有稳定方向偏差，再用已有数学 replay/refine 的有限 16/32 子步对照区分积分误差与剩余模型/投影误差。若误差随细化明显衰减，优先积分；若不衰减，保留表示/投影/物理假设。两者仍可能并存。只有事前容差内的方向预测，才进入实验二的实测检验。

**不能支持：** 完整物理模型等价、全局有效域、硬件精度、结构不可行；局部细化不能分离所有投影与遗漏物理。末步重读修复不能追溯修改原验收或原运行行为。

**计算资源：** 首阶段 CPU/文件读取，0 Provider、0 新物理、0 优化/训练；可选第二阶段为少数已存区间的既有数学 reintegration/refine，CPU+MATLAB，需另行授权，不跑完整 NMPC/物理仿真。

### 实验二：同候选上的数学方向与物理差分方向对照

**所需数据与固定条件：** 首选 `cfddd272…` 与其最佳已存控制；以一个候选一次实验为单位，保留原任务、基线输入、35 区间、通道顺序、结点/幅度/相同物理启动上限。复用 `controller_start_input`/exact execution 点的 `linearization`、`trajectory_feasibility` 或瞬时制动；将已有映射投到同一控制结点类。静态 IFT 单独以 0.2 N 内点候选为对照，不跨候选借用灵敏度。事前登记少量方向与符号、预计位置/速度改善，以及一个反方向或原 response 方向对照。

**可区分的假设与反证：** 数学方向在独立原验收中带来预期符号且减少同等启动预算下的 gap，支持“数学可替代部分盲目物理探测”。方向在模型自校验内成立而物理反向，否定该工况的转移假设。数学每区间控制可行而投影到结点类失效、且实际较丰富类成功，支持参数化限制；同模型同控制类下未找到见证则仍可能是优化未解决。若要比较两种控制类，预先限定为嵌套类并给相同尝试预算，不能同时换结构/目标权重。

**不能支持：** 未测试结构的能力排序、数学方法普遍优于物理差分、少量失败证明结构不行，或“局部方向正确即最终可通过”。比较了不同基函数类时不能把效果全归于方向选择。

**计算资源：** 少数候选绑定数学计算（CPU+MATLAB/SciPy）+小批独立 MuJoCo 开环验证；不用 Provider、完整 NMPC、NLP 大搜索或 PPO。以新物理启动数与有效方向数为主要资源指标，墙钟实测。复用原注册评价器，保持最终验收阈值。

### 实验三：冻结决策点的数学入口可发现性对照

**所需数据与固定条件：** 选择 S12.8 一个“已有合法候选、尚无 analysis、尚未大额 response-search”的真实 cutoff。只提供该时刻可达的证据/额度，禁止未来结果及 S12 成功答案泄漏。对照原实际广告/包与同一接口的最小展示变体：在现有动作反馈中显式列出可请求的 analysis 与工作点前置条件，澄清 `mathematical_response` 的 blocked 是缺输入灵敏度而非数学不可用。复用原 Schema、Store、工具、`decision_result` 和预算规则；不同臂随机顺序、多个独立单次决策，科学工具在执行边界截获。

**可区分的假设与反证：** 若变体提高候选绑定、Schema 合法、能说明范围的数学请求率，支持“入口发现/前置状态展示影响选择”；若仍选择有明确可检验理由的物理路线，削弱单纯发现性解释。统计有效请求率、选择的信息价值、是否误推结构不可行，以及 Provider tokens/延迟；不以强制选数学作为成功标准。

**不能支持：** 数学实际数值可用率、减少科学成本、通过原任务或 Agent 普遍科研能力。没有执行 scientific dispatch，就不能把 proposal 当新科学证据；不能仅凭自述理由建立因果机制。

**计算资源：** 小批 Provider-only 单轮决策探针，0 物理、0 NMPC/NLP/PPO；需要单独的 Provider 授权。本任务不调用，也不把它作为新的 Cold-start。

## 10. 最终验收判断

现有工具已经能够提出并验证**局部模型范围内**的平衡、输入作用、采样约束及必要条件排除；第一轮诊断缺的不是一个新的数学求解器。S12.8 的主要证据缺口是从未取得候选绑定的这些分析，研究行为大量投入有限控制参数化的物理响应搜索，不能据此排除结构能力。

同时，静态边界输入限制、局部模型无全局误差界、专用档案诊断的固定维数，以及末步标量广播，说明“有接口”不等于所有候选都有有效证据。先检查结果维度/身份/覆盖，再进行受控的数学→控制→独立物理转移；跨证据比较和选择行为应单独验证。封存 S12 的通过实例与 S12.8 的失败实例都保持原科学含义。
