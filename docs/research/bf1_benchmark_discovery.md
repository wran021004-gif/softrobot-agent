## 冻结候选与依据

第一任务候选为同结构的无外力、`[0,.02,-.03]` N、`[0,-.02,-.03]` N 三条件 Reach/Hold，作用在 payload body COM 世界系 `[.10,.35)` s。复用 B2 目标 `[.29,-.035,.19]` m、0.35 s 时域、.0005 s 积分、.01 s 控制/记录、最后 .05 s 保持和原全部验收阈值。正反横向分量对称，方向在物理筛选前声明；不根据结构胜负移动目标或载荷。payload 默认质量 .01 kg，重力约 .0981 N；横向 .02 N、向下 .03 N 分别约其重力的20%/31%，合力 .0361 N。这是有意义的外部扰动，不替换真实质量/惯量。

三份 `tasks/bf1_multidirectional_hold_v1_*.json` 是新命名开发任务，不改 B2 原 frozen_v1。第一轮只开放腱路覆盖/方向，三个代表结构均六通道，其余材料、尺寸、网格、驱动上限固定。精确候选集合在本地忽略目录冻结，公开配置只给内容身份，避免日后发布成功映射。研究者提出全程覆盖与分段作用的机制假设；这些不是未知结构的随机样本，也不是 Cold-start Agent 研究。

初始几何预检发现两组等相位腱路在基座连接点重合，按原 FamilySpace 几何规则拒绝。积分为零，保留诊断；在物理计算前交错相位解决连接点间距，再冻结最终候选。不是看到任务结果后的挽救。最终三结构×三条件的合法性、Native 适用范围、外力起止和六通道控制绑定均已零积分检查。

## 探索预算与停止规则

正式配置 `configs/research/bf1_multidirectional_screen_v1.json` 绑定任务、FamilySpace/工程源与私有候选身份。BF1 累计积分尝试上限 **3,500,000**，Provider=0，独立数学 worker=0。直接调用原数学/控制内核的全部内部积分照常计费。没有新优化器、评价器、Store 或 Agent 调度器。

每结构从 .2 N 起点出发，用统一三次 .05 s 两尺度 short_input_response（.01/.005 N）及原 constrained_response_step，修正半径 .5 N，向初始 tip/任务目标中点产生常张力种子，仅接受短时误差下降。三条件外力起于 .10 s，可共享本结构的新初始化；条件控制仍分别优化。不同结构不借控制，不读 B2 成功控制。若初始化发生接触/数值错误，保留并停止该起点，不无限重试。

每条件原 Native response 搜索：四 knots `[0,.05,.17,.30]` s，系数界8 N、差分.01 N、初始半径.5 N、内部1%余量；正式阈值不变。第一阶段最多151 callbacks/8 iterations；未通过者仅沿自身 best 追加301/12，均按原独立回放验收。每次完整 rollout 700 步，全部失败、短响应、Native 内部探测、回放均纳入同一累计账本。每个通过案例立即停止，不追更优分数。最多三结构九案例，不耗尽预算作为目标。

BF1 比较完整可行性线索、独立误差/速度/违反项、同资源结构差异、初始化失败与控制搜索成本。若多结构都易通过，保留控制优先负对照；若全失败，保留算法预算未决，必要时另行冻结最多一个多目标工作空间候选。不得把失败称结构不可能。
