# BF2：多方向保持的独立结构—控制验证

2026-10-27，Asia/Shanghai。BF1 已发现同结构三条件独立可行性及等六通道差异，因此启动 BF2。新版本 `configs/research/bf2_multidirectional_validation_v1.json` 引用 `tasks/bf2_multidirectional_hold_frozen_v1_{zero,positive,negative}.json`；原 B2 v1 与 BF1 开发记录保持不变。任务在验证前冻结，注册任务状态保留 development_valid；“正式验证”指本冻结研究协议，不冒称平台已给予另一种 formal TaskDefinition 审批。

## 正式冻结协议

同一结构分别完成无力及世界 payload COM `[0,±.02,-.03]` N 两受力条件，载荷 `[.10,.35)` s，目标 `[.29,-.035,.19]` m。0.35 s 时域、.0005 s 积分、.01 s 控制和采样、末 .05 s 六采样、终点/保持10 mm及保持20 mm/s、原重力/接触/张力约束均冻结。各条件独立全零初态与 seed17、合法控制重优化，原独立 MuJoCo 回放及完整复合验收决定通过。

两个新精确腱路实例各六通道，被动材料/尺寸/质量/网格相同，未在 BF1 执行；其机制类别受 BF1 启发，并非未经研究的随机结构样本。精确候选在私有文件冻结，公开计划绑定其摘要身份。每结构从 .2/.4 N 两个预先声明的确定性起点、共同短响应规则重新初始化；不读任何 B2/BF1 成功控制，不跨结构或条件借控制。

每条件使用原 Native response 算法与四 knots、边界、差分及1%搜索余量。未通过者按151 callbacks/8 iterations →301/12 →501/20三阶段继续各自 best；每阶段独立回放。通过案例立即停止搜索，第二起点与另一结构是必要公平对照。共有2结构×3条件×2起点=12案例。相同上限和控制维数保证可比机会，不意味着相同数值难度；没有等功率/等能量结论。

BF2 独立累计上限 **12,000,000** 次积分尝试，不继承 BF1 或 B2。按最大 callbacks、回放与共同初始化估算，当前冻结程序的完整上界约8,061,600步，额度有充分余量。所有短响应、控制内差分、失败/重试、部分步与独立回放实际计费。不会为了耗尽预算追加新结构或移动任务。

## 结果揭示前的结构选择

在任何 H0/H1 完整轨迹揭示前，保存了两者的原 Native 瞬时力学映射诊断、方案及内容身份：A 按固定 H0→H1，B 按局部独立广义力方向排序 H1→H0。实际采用 B 顺序。新精确实例尚未执行，BF1 开发类别和结果已知，因此这是在开发知识基础上的新实例前瞻选择，不是研究者全盲。

瞬时映射计算只用模型构建/forward和既有矩阵诊断，不积分。它无法证明0.35 s完整任务。C 的额外任务数学对照未实施：离散路由不能直接作为连续 A4/T2 导数变量；已有有限 T1/T2 比较本身需要支付控制重优化，不事后包装为免费预测。

研究将记录实际 B 到首个同结构三条件解的完整成本，并从同一公平案例的已付成本重构 A 顺序成本；后者明确是**反事实顺序重构**，不是独立随机策略实验。B 若先找到可行结构，H0 可在首解前延后，但公平验证仍会执行它，故不宣称全研究总计算减少或实际永久避免了这些实验。若数学没有改变候选或没有收益，照实保留。

## 完成结果与结论范围

12案例全部完成。**H1 在两个起点下均通过全部三个冻结条件，H0 在两个起点下三个条件均为 valid_failure。** 全部初始化和完整 Native 轨迹有效，无接触适用范围退出或数值失败。H1 六个案例均在首阶段独立通过后停止；H0 每案例用完预定三阶段的953次 Native callbacks，仍失败。

等六通道、相同被动参数/网格、张力边界及控制维数下，两个起点一致支持本有限算法中的腱路结构收益。所有结构均有效进入控制优化，因此不是单纯因某结构冷启动崩溃造成的胜负。仍不能排除其他控制族/优化器/初始化/预算让 H0 通过，也未将物理能力收益与结构改变带来的求解条件改善分离。这是有辨别力的联合设计候选，不是 H0 无解、H1 全局最优、硬件可靠或扰动鲁棒证明。H1 通过余量约1%，未进一步测试鲁棒性。

## 数学前瞻选择的实际结论

事前保存的B顺序 H1→H0 确实先选中完整可行新实例；瞬时映射秩为4/2。预检/诊断整体耗时约1.166 s、额外积分0；B的首解已记录执行段约21.271 s，段外准备/IO未全部包含。

按同批已付公平案例成本，A的固定 H0两个起点→H1首起点顺序重构为 **4,240,700** 次积分尝试；B实际首解为211,700，差额4,029,000。A数字是明确的反事实顺序重构，**不是独立执行的A策略实验或已证实的因果节约**。H0在首解前被延后，但公平验证仍完整支付它，永久避免的对照实验为0，不能声称本研究总计算减少。

BF1已让研究者知道机制类别的表现，已有开发知识也支持同一选择，因此未分离“新增数学信息”相对这些知识的额外收益。C未实施，也没有把已见结果包装成盲态数学预测。此次只支持廉价局部诊断在该新实例选择节点与物理结果一致、改变了相对固定标签规则的顺序；不支持数学工具普遍或独立地降低研究总成本。
