## 冷启动问题与共同初始化

首组原样使用每通道恒定 0.2/0.4 N 冷启动，16 个案例均未通过。其中 12 个 Native 基线因接触超出工具的无接触适用范围；8 个独立回放数值失败。原中性结构的四个搜索正常完成但任务失败。停止位置、部分积分、失败前状态、警告和支出全部保留，**接触或数值失败没有解释成结构不可行**。

零积分检查还暴露导向孔属于腱路变化，不能要求整个 components 逐字相同；保留首个预检断言失败后，核对除 guide_holes 外的全部被动物理字段和网格相同，再冻结对照。没有修改生成器或物理模型。另做的 16 次瞬时响应步骤仅为初始化诊断，没有采用其控制，也没有积分。

随后在新子协议中对所有结构采用相同规则：

1. 从原 0.2/0.4 N 标签出发，各调用三次原 `short_input_response_v1`，时域为接口允许的 0.05 s，两种有限差分步长为 0.01/0.005 N。
2. 用原 `constrained_response_step`，每次在 0.5 N 修正半径内，向“初始 tip 与任务目标的中点”提出常张力起点；再独立执行 0.05 s 检查，只保留短时位置误差下降的提案。该中点是**初始化诊断目标**，不替换冻结任务或正式验收。
3. 24 次两尺度响应检查全部通过，最大相对差异约 0.000367；仍仅是局部一致性，不是区域或完整任务保证。该时间段早于外力起点，因此两条件共用同一初始化规则，之后分别优化和独立验收。

初始化后的控制不再是恒定 0.2/0.4 N；这两个数仅标识两条独立研究起点。两个起点是确定性的，不声称统计独立。后续完整 Native 搜索均正常完成，未再遇到上述接触/数值失败。

## 数学解释与结论边界

等资源的 S2/S3 对照排除了“仅仅多几个驱动通道就足够”的解释：S2 经过更多优化机会后，受力条件仍约超限 14.8%，S3 在两个起点下均通过。它支持**本求解链、共同初始化和计算机会下的结构布置收益**，没有证明 S2 或 S0 在其他控制族/算法/预算下绝不可能通过。

对已经保存的初始直构型矩阵做事后检查，S2 的理想张力→广义力映射秩为 2，S3 为 4，与增加独立力学作用方向的解释一致。这是已有数据的四次 SVD，无新积分；不是事先预测六腱更优，也不是有限时域可行性、区域可控性或全局最优证书。

短时响应解决了本次求解链的初始化障碍，但没有单独等成本的初始化方法消融，不能据此声称数学工具普遍节省总计算。过程由本会话助手组织，仍不是自主 Agent 冷启动成功。
