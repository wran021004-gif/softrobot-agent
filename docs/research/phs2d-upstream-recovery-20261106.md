## 确认的本地恢复缺陷

首次恢复窗口 window007 在发送之前被 `SDK_INITIAL_CONTEXT_MISMATCH` 拒绝，累计仍为 18/64。
原 Handoff 已提交、连续两个首次请求都已失败结算，但初始快照校验仅接受恰好一次发送。
这是恢复编排缺陷，与科学数值资格和网络故障分别记录。

最小修复允许多个连续失败发送共享原初始快照，但逐一验证：
所有请求均有失败 receipt，HTTP 状态属于原有可恢复集合，purpose 为 conversation；
每份原始 wire 的历史必须等于当前已保存历史，末尾仍是原科研 packet；
不存在成功模型回合、工具请求/反馈、运行请求、pending 或未消费响应。
任一更早请求不合格即拒绝，不能只检查最后一次失败。
审计记录同时保留最后失败 ID 与完整失败 ID 列表。
修复本身不发请求、不创建重试循环，也不处理未知外发或改写旧失败。

定向 SDK Mock 回归覆盖：一次失败后的原恢复、两次连续失败后的恢复、全部费用保留、
恢复请求历史完全相同、快照篡改拒绝，以及更早失败 receipt 缺失/被改为成功时拒绝。
