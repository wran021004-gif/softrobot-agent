统一 Harness 已通过原 PHS 加载/重置/采样语义的名义数值准入：代表工况先满足预冻结一致性门槛，随后完整十工况在新 Study 中新鲜执行并由独立评价器 accepted。实体孔、固定腱路端点、payout 和材料参数已能通过现有研究接口选择和重建。正式自主 Study 已准备为空候选池，**没有启动 Provider；Gateway 不可重试 429 的恢复仍未确认，正式开跑仍需新的精确身份授权**。

新版本保留统一 Harness 已有的每步安全监测与保守有效性门禁；不能把本次有限结构对照宣称为所有结构的历史资格全域等价。原科学门槛没有放宽。静力研究仍是理想硬单侧约束、无接触机制诊断，不能授予动态验收；原生动力学仍使用软腱长限制。

1.2 另外修正了安装四元数的浮点来源：原 XML 使用 `0.70710678118654746`，先前桥接使用平方根向上舍入的值，相差 1 ULP。它会改变原生模型数组和静力求解的数值路径，不能用“姿态看起来相同”忽略。最终新 XML SHA256 为 `69bdda97d9579bb005b5d45894b5f16151f778030f3979246bc8950c73acce67`；原 XML 的默认零 margin 与新编译器省略该默认属性仍有文本身份差异，没有宣称 XML 字节相同。

## Main 可选择的数学参数

新增冻结域为 `family_space_phs2d_route_research_v2.json`。复用现有 Domain、参数 catalogue、敏感性授权、selected-parent `changes`、模型构造和求导路由。

- 实体孔：`guide_hole_positions_m.<真实板>.<实际使用孔>.1/2`，单位 m，局部 y/z；冻结范围 ±23.5 mm，仍需原实体包络、孔间距和路线合法检查。孔半径、实体质量和惯量保持原模型语义。
- 已有显式固定端点：`route_overrides.<腱>.<点>.attachment.position_m.1/2`；固定基座局部平面和 payload 实体包络分别绑定。错误锚点、未知孔、未使用孔、越界及穿透均不能获得物理执行资格。
- payout、Young 模量、实际截面尺寸、截面方向和已注册黏性材料变量继续走原接口。新域显式纳入原合法原型继承的根段黏性值，避免把既有继承值 materialize 后反而落在显式覆盖域外；未改变旧域、原型物理值或验收。
- 不注册孔轴向坐标；对象/拓扑/离散网格不获得普通结构梯度。坐标是否可生成、是否获 Study 数学授权、工作点是否正则、探针是否有效是不同资格。

selected-parent 修改保留其他实际解析字段，并由原生成器真正重建板孔和腱路；参数路径不是 XML 或 MuJoCo 数据字段。未授权路径返回原授权原因；非法探针保留失败。实际腱长 Jacobian、正张力集合、边界单侧锥、零空间和局部柔顺性来自原注册硬绳内核。

真实孔变量 Worker 完成 5 个模型、10 次平衡求解、1,440 个 Hessian 列、5,490 次 native forward、**0 积分**。所有探针属于同一正则活动集，但两尺度相对差 0.45649，大于原 0.1 门槛：结果为 `unreliable`，没有结构方向或可信梯度。不能以“正则”掩盖数值不一致。张紧集合切换或失效/非正则探针会撤下梯度和建议方向，只保留明确标注的有限比较。真实小模型测试还验证边界单侧 QP、活动集切换、容量失效与拓扑变化时不发放普通梯度。

最终干净的 69 项定向回归全部通过，另 2 项新增的状态投影/真实十工况分母测试通过；包含它们的完整 11 项原协议测试模块也通过，合计 71 个不同测试。定向回归覆盖旧连续协议序列化、原初态/cold reset、十工况成本、九段四腱生成、实体孔越界和错误锚点、真实实体穿透、selected-parent 真实重建、权限、正则资格、失效梯度、有限增补事务、被动 SDK、Reporter、独立证书、SELECT/STOP 和恢复。缺失的仓库固定依赖 tokenizers==0.22.2 已补到现有研究环境，随后使用该环境测试；没有切换 Provider 或发送探测。

扩展旧套件没有被伪报为全绿。仍有三项旧夹具问题在本轮修改前的 bd25092 工作树复现：完整数学 SDK 夹具预期扣 7 而实际扣 6，以及两项旧结构搜索夹具。旧 MATLAB 后端恢复套件缺 matlab.engine，不能冒充当前被动后端恢复证据。本轮修正了两个陈旧夹具的前置构造，使真实活动集边界和已初始化 Store 快照断言实际运行；没有修改生产 Store 行为。Windows 长路径 Gateway 丢响应夹具已确保实际超过 260 字符，使用 Mock HTTP，无真实 Provider。
