# 轻量被动 Study 科学诊断（2026-11-05）

结论：主导失败是冻结的受力材料点位移上限，未建立有效被动腱约束。有限搜索未找到解；没有数学证明该设计空间无解。原任务不是 PHS 的形变解耦合同：它要求 s=0.5 材料点在正向 0.006 N 世界-y 力下几乎不动，没有要求受力点至少移动 10 mm，也没有独立 Tip 抑制目标。Main 沿提高截面抗弯刚度的方向取得进展，与其收到的轻量合同一致，却不能回答 PHS 问题。

原指标是相对同 episode 无载最后样本的三维材料点位移范数，在 [0.38,0.40] s 上取最大值；不是 Tip 位移，也不是米与毫米混淆。带符号目标为 max((observed-bound)/abs(bound))，因此最后 Replay 的 44436.8346 是无量纲超限量，对应 4.4437834578774885e-5 m，而不是 44436 米。无接触约束始终通过；它作为不能归一化的硬门禁保留，不被优化器忽略。

两个新隔离 Store 的新鲜 Replay 复核：1 ms 得 4.4437834578774885e-5 m；0.5 ms 得 4.438666917967802e-5 m；差 5.116539909686752e-8 m，即 51.1654 nm。共真实积分 1500 步，均 valid_failure。两步长差不是严格误差上界，但已经超过冻结阈值约 51 倍。当前44.4 μm超限远大于这次51 nm变化，历史失败不会因精度风险变成通过；风险针对阈值附近的可信判别。步长变化同时改变积分与力加载离散化，这项对照是数值协议敏感性，不是纯积分截断误差估计。原卸载资格还允许 0.5 mm 尾窗漂移、1e-5 N·m 静力残差和 50 μm 腱长超限，这些容差不是位移误差的直接换算。结论是科学任务定义风险，不能改阈值后追认通过。

## 腱、零空间与外力

保存的基线/禁用配对中，payout=0.1601 m，初始实际腱长 0.16 m；高载阶段实际长度约 0.1599795–0.1599842 m，比 payout 短约 116–120 μm。基线全程标签 slack、实际张力 0；禁用后相同阶段为 disabled，长度、状态与位移保持一致，最后 qpos 配对差为 0。11 次独立 Replay 的每一步最大张力也全部为 0，保存样本均为 slack；最后候选的材料点指标约 44.437835 μm，同时 Tip 实际位移约 98.329384 μm。所有独立 Replay 的张力及松弛量另逐条保存在原始审计中。现有原任务只测试一个正向力，不能据此推断所有反向载荷均松弛。

新隔离注册 mechanism_structure_v1 请求进一步执行真实硬绳静力诊断：1 次评价、1 次模型构建、2 次平衡求解、4 次优化迭代、0 积分；加载平衡 qualified，active/positive/boundary 数均为 0，slack 数为 1，张力 0，松弛余量 108.991 μm，驻点残差 3.30e-10 N·m，最小约化刚度约 0.4905 N·m/rad。实际 J_length 是 1×4 非零矩阵，但可行锥等式/边界不等式都为空，不能把全部几何行当作有效约束。外力通过实际 J_pointᵀF 激发第一单元两个弯曲自由度。

J_tip 是 3×4、局部秩 2；即使假设唯一腱成为双侧约束，其全部 J_length 行空间对 Tip-y 的相对残差仍约 0.2860。单行秩约束最多消去一个局部方向，保留 3 维切空间；材料柔顺性仍可让实际外力激发 Tip 运动。这只是局部假设性 B 型风险。实际观测首先支持 A：该腱没有激活；不支持把 C（阻尼/时域使合理张紧机制失败）作为当前主要解释，也没有排除未来其他载荷或其他 payout 下的 C。

注册数学工具能区分 slack、positive、boundary、J_length、J_tip、KKT、约束零空间/单侧锥、切线柔顺性与外力响应；非正则情况有资格门禁。它具备做这种机制诊断的内核。Main 的现有结构改动主要改变 EI 张量及质量，未改变实际张紧约束机制；原合同和只能一段一腱的授权域也促使搜索停留在“减小所有受力点运动”的路线。继续局部增刚可作为有限诊断，但没有可靠证据说明它能实现 PHS 的大受力点位移与小 Tip 位移共存。后续应独立冻结可改变实体腱路、payout/张紧方式、腱数量和拓扑的域，并由 Main 自主选择；不能扩大原 Study 来掩盖版本差异，也不能把历史赢家作为初始化。
