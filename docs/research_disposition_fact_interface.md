# 主线三正式处置事实选择接口

`selectable_facts_v3` 是新活动显式选择的调查契约，模型适配器为 `deepseek@8.0.0`。机器人控制器仍是 `controller.gvs_nmpc@9.0.0`，此适配器编号与实验控制器 v8 无关。旧活动保留原契约和原失败。

主模型收到完整报告、反证、未知项、公共原始资料读取记录和有名称、原值、用途的事实目录。`dispositions` 选择报告、目录版本、采纳／暂缓／拒绝、判断、事实句柄、适用范围、解释和未知项。支持报告判断的 `supporting_facts` 与主模型补充的 `additional_support` 分开；`scope` 表示适用范围。目录可通过同一按需证据读取服务取回，目录可见性不替代原始资料检查。

每个句柄绑定不可变报告与执行身份、原报告项位置、原始来源、字段位置、精确 JSON 类型和值。相对子字段 `projection` 只允许 JSON Pointer 提取，保留原值、单位字段和数组顺序；不计算、不强转、不近似、不推断。程序保存模型选择和确定性展开，展开关系包含原报告项、原事实、投影和正式事实，公共处置再检查这一展开及权限、报告读取、原始来源读取和科学适用范围。未知句柄、错误报告、版本、执行或修改后的正式值均拒绝。

结构正确不等于科学判断正确。公共回执继续标记解释未经语义审查，阶段推进另需人工／Codex 阅读实际报告和决定形成独立审查证据，不增加付费裁判模型。程序不替模型选择判断，也不强制采纳。错误反馈保留决定位置、句柄、原因与合法结构；当前纠正请求保留报告、原始证据、追加页面、错误和剩余额度，先前完整思考及请求留档并声明可查询。

本次原失配的逐项对照见 `evidence/research_disposition_facts_20261008/specific_mismatches.json`。其中 34 项为精确报告事实，6 项为原始资料中值正确但子报告未记录的主模型新增依据；该支持事实集合没有对象到叶字段的拒绝。原响应及报告未改写。
