# 主线三版本一：本轮冻结的错误分流与指标审查

本轮建立新活动，起点为 `6b4f7d85e4ae937ba6117afde1e47cd9fcc6a36c`。旧活动、节点、停止状态、费用和未知预留保持封存。工程准备不启动真实模型节点。

| 错误类别 | 处理入口 | 费用归属 |
| --- | --- | --- |
| 程序构造、展开、保存 | 本地修复；原回答可恢复时原样重验 | 工程时间；既有付费请求不退款 |
| 完整请求或报告容量 | 检查真实发送对象及原始选择、展开、档案大小；先本地解决 | 容量检查不产生模型费用；必须改变输出时才授权纠正 |
| 模型协议 | 具体决定路径、句柄、错误及合法结构反馈 | 同一阶段、同一节点模型尝试及纠正预算 |
| 证据不足或推理 | 独立审查指出具体解释、冲突/缺失依据及查询入口；允许补查、修正、暂缓或拒绝 | 确需改变模型选择时计付费纠正；不增加模型裁判 |
| 传输或结果未知 | 核对原请求、保存回答、公共回执与账本；保留未知预留 | 原请求保留费用和预留；零自动传输重试 |

程序来源链存为不可变独立档案，不重复嵌入模型报告。事实句柄只还原精确值、来源和投影，不替模型选结论。新增主模型依据、子报告支持和适用范围分别检查。

指标视图仅使用历史候选配置、对应评价器版本、官方评价和原信号。Stage336 的 `evaluate.reach@1.0.0` 以完整采样执行的终点距离验收；保持窗口由当时 `controller.gvs_nmpc@6.0.0` 的控制报告单独记录。新的联合验收不覆盖旧官方评分。整体失败不能一般性推出某个分项失败；无法独立复算也不能抹去明确的官方记录。

审查比较具体判断、选用依据、保留未知及其对结论或后续行动的影响。采纳、暂缓和拒绝均允许；措辞问题单独记录。单步预测吻合度不支持到达或保持成功，不支持因果、全局最优或实机实时部署。

阶段 A/B/C 门禁、独立审查版本、生产代码、预算和绝对截止在真实调用前冻结。节点经过时间包含修复和暂停；纠正沿用同一逻辑节点，费用不退还。最终 30 分钟保护交付。本轮不开发版本二结构。
