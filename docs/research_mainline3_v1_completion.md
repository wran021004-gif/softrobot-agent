## 接口和离线证据

`selectable_facts_v3` 让模型选择报告、采纳／暂缓／拒绝、判断、事实句柄、范围、未知项及解释；程序从不可变 Store 档案填入精确引用、值和身份，再执行公共处置校验。`supporting_facts`、主模型 `additional_support` 和 `scope` 分开。程序不选择结论、不自动采纳、不把句柄合法当作推理正确。

目录显示全部句柄的名称、来源路径、精确内容、类型和用途规则；完整报告绑定、原事实项及身份链可按需读取。`projection` 只允许 JSON Pointer 提取真实子字段，保留原值、类型、单位内容和数组顺序；禁止计算、强转、近似和推断。未知句柄、错误报告／执行／版本及修改后的展开值均拒绝。公共过程产生来源检查及实际读取记录，模型不能自称“已核验”替代检查。

完整选择、展开和来源链留档并可逆向核对。来源链用不可变档案引用保存，避免膨胀模型报告。错误反馈带决定位置、句柄、原因和合法结构。新证据／纠正轮次明确声明旧思考只留档，保留报告、反证、未知项、确认读取结果、恢复上下文和权限预算，并提供实际响应查询引用。结构正确不等于科学解释正确；阶段另做 Codex 阅读审查，没有额外付费模型裁判。
