### C1：PHS-2D的自主科研决策

**贡献与理由。** 原记录存在清楚的非线性改向：腱松弛→局部运动耦合→有限载荷停稳失败→实体穿越→七段实体导向→间隙/刚度调整→六工况筛选→冻结十工况。关键不在于多调用工具，而在于何时否定假设、改结构或转向几何检查。

**两臂差异。** Full可以根据返回的物理/数学证据改变问题、工具顺序、变量和研究路线。Fixed-Plan在运行前登记固定的工具序列、有限候选网格、预算分配、停止规则和候选排序；它仍能读取返回值用于规定的排序和验收，但不能依据新发现自适应增添机制分支。合法schema修正和传输重试两臂一致，不能把技术错误当作失去科研能力。固定计划由独立于最终F8答案的任务规范制定，不能照抄已经知道的成功路径。

**必须一致。** F0或预登记的同一合法初始生成规则、设计域、载荷/方向/材料点、积分器、停稳窗、几何检查、数学底层能力、Knowledge/Skill可见性、候选/数学/物理/墙钟预算、独立确认预留，以及完整十工况验收。主搜索工况与冻结后确认工况的角色沿用原协议；确认结果不得反向用于继续调参。F8及其成功轨迹不作为任一臂的初值。不要让Full额外看到固定计划臂不能访问的历史答案。

**主要指标。** 配对重复中的完整十工况可行率、全部约束的最终违反量、首次完整可行的时间（未成功者按预算右删失）、物理回合与积分步；过程指标选择有证据的改向、失败恢复、重复失败和假设修订。Fixed-Plan的假设修订率结构上接近零，只作操作校验，不能将这个差异当作任务效果证据。

**待检验现象。** Full可能在停稳或实体穿越后更快换分支；也可能因探索开销更大而无优势。两种结果均可解释。现有11节点支持“发生过自主改向”，不足以证明相对固定计划更有效。需要新的匹配重复；本轮不执行。

### C2：数学研究架构

**操作定义。** Full-Selective通过研究问题组织、适用性判断和选择层决定分析。Direct-Math-Tools保留同样底层数学方法、参数域、结果字段、物理后端及合法调用示例，直接向Agent暴露这些工具；移除高层问题组织和选择层。Direct仍可自主选择是否调用，不能强制其做无意义分析。两臂相同的合法请求校验、物理初始化及必需数学计算不能删除。实施前需确认当前接口确实能单独绕过选择层；若必须同时改变工具权限或求解器，则不能称为此因果对照。

**M2为什么合适。** 原研究已记录静力方法不支持实际外力，因此应尽快转向受力原生控制响应。比较两臂是否同样识别不适用，以及是否产生额外无用分析。不能预先认定该任务完全不需要数学：最终控制响应搜索本身仍是必要计算。

**PHS-2D为什么合适。** 原过程包含局部QP信息、有限载荷响应、几何检查和多工况验证，能够检查数学结果是否进入真实结构决策。局部低传递比不保证有限载荷或远端工况通过，不能只优化某个局部代理得分。

**固定条件。** 同任务、初始规则、Agent配置、Knowledge/Skill、底层工具实现/容差/权限、数学计费定义、物理预算、候选预算、输出信息量与独立确认规则。必需执行器、平衡及后端内部计算两臂相同。每个数学请求记录实际算法、内部目标评价/迭代及是否包含物理积分，防止仅因适配器换名而出现虚假成本节省。

**指标。** M2以相同三工况通过率为效果门槛，主报无效数学调用比例、首次可行成本和数学评价；PHS主报相同预算下完整十工况性能、数学到行动率、无效分析比例及失败恢复。数学次数低本身不是好结果，必须同时满足效果与验收范围。计算数学到行动率时分开“改变设计/控制”“确认/停止”“不可用”，避免抹去必要验证。

**现有支持与缺口。** 当前节点支持数学反馈实际影响决策的过程解释，但没有Direct同工具对照。需要上述新匹配实验，不能用P3历史No-Optional-Math替代C2。

### C3：T04的Knowledge+Skill

**贡献与理由。** 当前实际读取包括历史跟踪、方法选择、原生平衡初态、平衡组和相位/预张力经验。后续从原控制路线转入平衡组，出现全4 N初始化失败，再用局部平衡与内点预张力恢复。适合研究路线选择和初态构造，而不仅比较最终RMSE。

**差异与公平性。** ON可检索指定版本的Knowledge与Skill；OFF移除这些历史条目和方法配方，保留同样任务说明、通用文档、工具可发现性、schema、构造与资格能力。两臂相同的通用接口帮助不能被OFF移除。清理提示/缓存/候选初值中的历史成功张力和目标轨迹；若保留某种答案信息，必须两臂等量可见并单列。OFF失败不能来自隐藏合法工具入口。

**固定条件。** 同合法几何初始规则、22 s原参考、相同两周期/双叶/漂移要求、初态资格门槛、负载及所有执行器限制、预算与确认预留。禁止ON直接复用已成功的89点组作为验收；ON也必须在当前模型上构造、资格确认并独立执行。

**指标。** 首次合格初态与首次完整可行成本、完整路径最大/RMSE、周期漂移、重复失败、路线切换次数及原因、历史经验迁移成功率。迁移成功的分母为实际尝试迁移的具名历史规则，不是条目读取数；成功要求满足规则适用条件且当前执行独立有效。联合ON/OFF只能识别Knowledge+Skill组合效应，不能分别归因给两者。

**预期与数据边界。** ON可能减少错误方法和边界初值反复，也可能引入不适用历史几何；必须同时报告正迁移与负迁移。现有Trace提供具体机制证据，尚无OFF臂，不能报告减少比例。

## 统计与过程指标的预登记

先做3个配对种子的可行性pilot，检查干预是否只改变目标组件，再依资源预登记确认性重复数（例如至少5对；最终数量须据方差和预算决定，不在此虚构功效）。以相同初始规则/种子配对，保存全部失败，独立确认预算两臂相同。报告每臂成功次数/总次数及区间；跨不同任务不简单平均误差或拼成一条收敛曲线。

| 指标 | 可操作定义及注意事项 |
|---|---|
| 完整可行率 | 完整冻结任务全部required通过的重复数 / 全部有效启动重复；control单列 |
| Final Constraint Violation | 每项原约束的signed/normalized violation分别保存；归一化遵循冻结协议，不能临时改尺度 |
| Multi-condition Pass Rate | 同一最终结构/要求共同控制器的工况通过数 / required数；不拼接不同候选最佳工况 |
| Time to First Feasible | 首次完整独立验收可用时间减研究启动时间；未成功者右删失，不能仅平均成功重复 |
| Evidence-grounded Decision Rate | 明确链接先前证据且解释所选行动的科学决策数 / 可评估科学决策数；技术重试另列 |
| Hypothesis Revision Rate | 有相反证据后明确修订/放弃假设数 / 有可判定反证的假设数；不是越高越好 |
| Failure Recovery Rate | 在剩余授权预算内通过新研究行动恢复为可行的失败分支数 / 有恢复机会的失败分支数 |
| Math-to-Action Rate | 后续明确驱动设计/控制/路线/停止的可用数学报告数 / 全部可用数学报告数；确认性验证另列 |
| Repeated Failure Count | 已知相同失败机制下，无新假设而重复同规范化结构/控制/工况；所需独立确认不计重复失败 |
| 无效数学调用比例 | 不适用/无新增可用信息/失败分析分别标注后占数学尝试比例；schema错误与数值无信息分开 |
| 重复失败减少比例 | 只在配对ON/OFF重复中按同一规则比较；当前读取次数与单条成功不能计算此比例 |

由双人按预登记规则对科学决策进行盲编码更稳妥；若只进行自动Trace标注，须报告规则、分母和误判抽查，不能把工具数量当作决策质量。以上均为未来实验要求，本轮未实施。
