# Full 实际研究能力盘点

本文件只盘点 `m1-core-full-20261111` 和 `p3-passive-progressive-stiffness-autonomous-20261110-v1_2` 的既有使用。依据已整理案例、保存的结果摘要，以及针对已有 retrieval 引用的少量只读条目核对；没有重导出 Store、新建证据索引或执行实验。数值及成本见 [M1](M1_full_results.md)、[P3](P3_full_results.md)。

“是”表示存在已执行调用或保存结果，不表示该能力独立导致最终成功；“否”指该项未在已整理实际链条中发生；UNKNOWN 表示现有材料无法确定。影响栏区分研究决策与最终设计收益。启用、授权、计划、工具注册和实际执行不是同一事实。

## Recommendations for Ablation Design

以下仅为下一阶段建议，本轮不启动任何消融。No-Math、No-Mechanism 和 No-Coupling 有嵌套关系，不能当作互相独立的加性贡献。后续各任务内需固定任务、结构设计域、初始信息、预算、软件版本及评价口径；本轮既有 Full 的版本/用户干预应作为历史限制记录。

| 消融 | M1 建议 | P3 建议 |
|---|---|---|
| No-Math | **优先。** 移除实际 Native/Direct 数学研究；明确是否保留物理响应探针，因为其实际成本属于物理评价。保留原任务独立评分和相同物理预算 | **优先。** 移除实际数学诊断/对照/交互/数学驱动搜索；明确被动任务的常规物理评估仍可用，避免同时取消结果评分 |
| No-Knowledge | **暂不列主要 Main 消融。** 未记录 Main 显式读取，只有 Reporter 读取基线。若做，需限定为 Reporter 或整体知识通道，实际决策效应尚 UNKNOWN | **推荐。** Main 已读被动力学、研究流程和 Skill，Reporter 也有实际读取；移除知识正文/检索及同源预载信息，明确是否同时包含 Skill/专家流程，保留工具说明与任务定义 |
| No-Mechanism | **缺少独立结构机制数学基线。** 不把控制优化或单坐标物理探针重命名为机制分析 | **推荐但需限定接口。** 移除给 Main 的活动集、腱状态及机制诊断能力，保留任务级位移/恢复/刚度结果；底层必要物理约束和初始化仍执行。否则会混成 No-Math 或改变物理模型 |
| No-Coupling | **缺少独立结构耦合基线。** 多通道控制优化已属于 No-Math，未完成的六通道拟合不能提供对照 | **有条件推荐。** 先定义为移除已实际使用的双参数四点交互，保留单坐标对照与相同设计域。若还禁止联合参数修改，应另列实验定义；专门 Coupled Block 工具消融暂缺确认基础 |

当前缺失：P3 完整 Token/美元费用汇总；Reporter 解释对 Main 决策的独立影响；M1 未记录的其他知识暴露渠道；P3 专门 Coupled Block 的实际执行确认。没有用猜测补齐这些字段，也没有为消融准备而补跑机制、敏感性或验证实验。
