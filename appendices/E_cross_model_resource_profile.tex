\section{Cross-model workload profile}
\label{app:cross-model-profile}

This supplementary comparison records the workload of two complete system snapshots across the same eleven task identifiers: the historical GPT-6 Astra FULL run and the current GPT-5.6 Sol FULL/K+S+ run. Both snapshots report eleven final task passes and zero final normalized constraint violation. The comparison is descriptive and is intended to show how research workload is distributed across tasks and resource types.

The four panels separate charged mathematical evaluations, physical launches, Core request records, and total tokens. Physical launches include unsuccessful starts; request records include research reads and decisions as well as tool interactions. The historical token total is estimated from the available request records, while the current token total is a recorded lower bound. These measurement differences, together with the distinct system snapshots, mean that the comparison should not be interpreted as an isolated causal model ablation.
