\section{Cross-model workload profile}
\label{app:cross-model-profile}

This supplementary comparison records the workload of the four Knowledge/Skill configurations and two complete system snapshots across the same eleven task identifiers: the historical GPT-6 Astra FULL run and the current GPT-5.6 Sol FULL/K+S+ run. Both snapshots report eleven final task passes and zero final normalized constraint violation. The comparison is descriptive and is intended to show how research workload is distributed across tasks and resource types.

The main-text Fig.~\ref{fig:knowledge-skill-resources} uses only the four current Knowledge/Skill configurations and applies independent min--max normalization within each task and metric: $z=(x-x_{\min})/(x_{\max}-x_{\min})$, with extrema computed across available configurations. This removes both the absolute level and the range of workload differences between tasks. Equal-valued resource groups have no contrast and are marked Equal with all bars at mid-height (stored as $z=0.5$); missing values are excluded from the extrema and shown separately. Consequently, bar heights do not measure percentage savings or the magnitude of a difference between tasks or resource types. Completion markers distinguish low workload from successful completion. The aggregate panel sums the raw records across the eleven tasks, then normalizes each resource total independently across configurations. The K$+$S$-$ token sum excludes the missing T06 record and is marked as an incomplete lower bound (ten of eleven tasks), rather than a complete total. Figure~\ref{fig:architecture-resources} and Table~\ref{tab:resource-ablation} report the absolute task-wise profiles and totals. The four panels separate charged mathematical evaluations, physical launches, Core request records, and total tokens. Physical launches include unsuccessful starts; request records include research reads and decisions as well as tool interactions. The historical token total is estimated from the available request records, while the current token total is a recorded lower bound. These measurement differences, together with the distinct system snapshots, mean that the comparison should not be interpreted as an isolated causal model ablation.
