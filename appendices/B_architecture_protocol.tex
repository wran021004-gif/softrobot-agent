\subsection{Research Interfaces and Shared Conditions}
All three interfaces share frozen task contracts, admissible design spaces, structure generation, physical models, and independent evaluation. LLM-only revises structures and controls from simulation feedback. Direct Mathematical Tools additionally exposes Jacobian, equilibrium/KKT, finite-difference, and supported optimization operations, with the agent constructing each problem directly. The full framework compiles research intents into task-conditioned problems and routes their mathematical execution.

Each task--method configuration uses ten runs under the per-run budgets specified in Section~\ref{subsec:setup-comparisons}. The archived GPT-5.6 Sol baseline and full-framework configurations specify medium reasoning.

\subsection{Acceptance and Resource Aggregation}
A task is completed if at least one run selects a candidate satisfying every required condition of its frozen contract. The three-interface comparison reports task-level completion. Resource statistics are reported for the Knowledge/Skill ablation and full-framework backbone comparison: each task's value is the minimum for that metric among passing runs, or the mean across all ten runs if none passes; portfolio totals sum these values. Mathematical operations count analysis or optimization calls, physical evaluations count independent task evaluations, and agent requests and tokens follow recorded usage.
